  Hydra application or a new `@hydra.main` decorator in `__main__.py` that wraps an already-decorated
  function — that produces a double-decoration crash.

- **Delegation pattern:** Whether `__main__.py` simply imports and re-exports `main` from the
  chosen delegate module (preferred: zero new Hydra config) or defines its own thin wrapper. If the
  chosen delegate's `@hydra.main` call already handles all config resolution, the cleanest
  `__main__.py` is:

  ```python

  if __name__ == "__main__":
      main()
  ```

  Do not layer another `@hydra.main` on top.
