## Provisional intent (judged against until Stage 4)
(Provisional) The project exists to predict 3D RNA tertiary structure from RNA sequence by composing a staged neural+geometric pipeline: secondary-structure/adjacency (Stage A), torsion-angle prediction (Stage B, neural TorsionBERT + Pairformer), forward-kinematics reconstruction to atomic coordinates (Stage C, MP-NeRF), and optional diffusion-based refinement (Stage D, AlphaFold3-inspired), packaging this for research and for Kaggle RNA-folding competition submissions (README.md:65-127, rna_predict/kaggle/**). README marks Inference as Functional, Training as Experimental, and Diffusion as a Research Prototype (README.md:7-11), so the apparent primary deliverable is sequence-to-structure inference producing CSV/PDB/.pt outputs (README.md:35-44). Stage 4 may refine whether the Kaggle harness or the general inference API is the dominant intent.

## Architecture
RNA_PREDICT is a Python package (package name 'rna-predict', version 2.0.8 in pyproject.toml:6-7) implementing a multi-stage RNA 3D structure prediction pipeline inspired by AlphaFold but specialized for RNA (README.md:69-99). The pipeline is organized under rna_predict/pipeline/ into four stages, each runnable standalone via its own Hydra @main and orchestrated together by runners: Stage A predicts 2D adjacency / secondary structure (RFold) in rna_predict/pipeline/stageA/run_stageA.py:153 with adjacency code under stageA/adjacency/ and a large input-embedding/transformer subtree (stageA/input_embedding/current/**, with a parallel legacy/ tree); Stage B predicts torsion angles, combining a Pairformer pairwise branch (rna_predict/pipeline/stageB/pairwise/main.py:90, pairformer*.py, protenix_integration.py) and a TorsionBERT sequence branch (rna_predict/pipeline/stageB/torsion/torsion_bert_predictor.py, using HuggingFace model 'sayby/rna_torsionbert' per README.md:53,193), with stageB/main.py:518 as the combined entry; Stage C performs forward-kinematics 3D reconstruction from torsion angles via an MP-NeRF implementation (rna_predict/pipeline/stageC/mp_nerf/** and rna_predict/pipeline/stageC/stage_c_reconstruction.py:491, run_stageC at :421); Stage D performs AlphaFold3-inspired diffusion refinement (rna_predict/pipeline/stageD/run_stageD.py:310,392 plus stageD/diffusion/** and tensor_fixes/, memory_optimization/). Configuration is centralized through Hydra/OmegaConf: rna_predict/conf/default.yaml (composed from per-stage YAMLs in conf/model/ and a structured schema in rna_predict/conf/config_schema.py registered via register_configs()), with a global mode flag selecting predict vs train (conf/default.yaml:18). The high-level inference API is the RNAPredictor class in rna_predict/predict.py:21 (re-exported through rna_predict/interface.py:6-12), which chains Stage B torsion prediction + Stage C reconstruction; the full A->B->C->D chain lives in rna_predict/runners/full_pipeline.py:334 (run_full_pipeline), re-exported for compatibility by rna_predict/run_full_pipeline.py:8. Training uses PyTorch Lightning (rna_predict/training/train.py + rna_predict/training/rna_lightning_module.py). Supporting subsystems include a Kaggle-competition harness (rna_predict/kaggle/**), dataset loaders/preprocessing (rna_predict/dataset/**), utilities (rna_predict/utils/**), benchmarks (rna_predict/benchmarks/benchmark.py), and developer tooling. The repo also vendors two largely unrelated subsystems: a Node.js 'Task Master' AI dev-task CLI (package.json scripts -> scripts/dev.js) and a standalone screen-finder GUI app (scripts/screen_finder_app/**). The canonical runner is 'uv run' rather than direct python (README.md:28).
